# Flowers by Lara Admin Portal

Mobile-first admin UI for the Flowers by Lara team, built as a separate Vite app with React, TypeScript, Tailwind CSS, and React Router.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The current interface is a front-end prototype. Changes are saved in this browser and can be restored from the workspace menu. Live orders, customer messages, account access, payment status, image storage, and website publishing still need the planned server connection.
