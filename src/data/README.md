# Nigerian location data

`nigeria-locations.json` lists the 37 Nigerian states and the 774 local government areas (LGAs) under them. The source identifies LGAs, not every informal town or neighbourhood; the editor labels these locations as LGAs/towns for staff clarity.

Source: [Open Admin Data — Nigeria Administrative Divisions](https://github.com/open-admin-data/nigeria-administrative-divisions), dataset dated 2026-06-01. Licensed CC BY 4.0.
